# 🛍️ Website Thời Trang (Fashion E-commerce Website)

Dự án website bán hàng thời trang tĩnh (HTML/CSS) đa danh mục, giao diện thân thiện, hỗ trợ trải nghiệm mua sắm trực tuyến với các trang chủ, trang sản phẩm (Nam, Nữ, Hàng cao cấp), giỏ hàng và liên hệ.

---

## 📁 Cấu trúc thư mục dự án

```text
Webthoitrang-main/
└── UT Webthoitrang-main/
    └── trang web th i trang/
        ├── index.html        # Trang chủ
        ├── index.css         # CSS cho trang chủ
        ├── nam.html          # Trang thời trang Nam
        ├── nam.css           # CSS trang Nam
        ├── nu.html           # Trang thời trang Nữ
        ├── nu.css            # CSS trang Nữ
        ├── luxury.html       # Trang thời trang Cao cấp (Luxury)
        ├── luxury.css        # CSS trang Luxury
        ├── giohang.html      # Trang giỏ hàng & thanh toán
        ├── giohang.css       # CSS trang giỏ hàng
        ├── lienhe.html       # Trang liên hệ
        └── lienhe.css        # CSS trang liên hệ
        ✨ Tính năng chính
Trang chủ (index.html): Giới thiệu các bộ sưu tập nổi bật, banner thu hút và điều hướng nhanh đến các danh mục sản phẩm.

Danh mục sản phẩm đa dạng:

👕 Thời trang Nam (nam.html)

👗 Thời trang Nữ (nu.html)

✨ Hàng cao cấp (luxury.html)

Giỏ hàng (giohang.html): Cho phép người dùng xem lại các sản phẩm đã chọn, cập nhật số lượng và tiến hành thanh toán.

Trang liên hệ (lienhe.html): Cung cấp biểu mẫu gửi thông tin, ý kiến đóng góp hoặc yêu cầu hỗ trợ từ khách hàng.

🛠️ Công nghệ sử dụng
HTML5: Xây dựng cấu trúc trang web chuẩn SEO, semantic.

CSS3: Thiết kế giao diện, bố cục hiện đại, responsive cơ bản.

🚀 Hướng dẫn sử dụng / Chạy dự án
Clone hoặc tải mã nguồn về máy tính của bạn.

Giải nén tệp (nếu ở định dạng .rar/.zip).

Mở thư mục trang web th i trang trong trình soạn thảo mã nguồn (ví dụ: Visual Studio Code).

Mở tệp index.html trực tiếp bằng trình duyệt web (Chrome, Edge, Firefox,...) hoặc sử dụng extension Live Server trên VS Code để có trải nghiệm tốt nhất.
