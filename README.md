# 🛍️ Website Thời Trang (Fashion E-commerce Website)

Dự án website bán hàng thời trang tĩnh (HTML/CSS) đa danh mục, giao diện thân thiện, hỗ trợ trải nghiệm mua sắm trực tuyến với các trang chủ, trang sản phẩm (Nam, Nữ, Hàng cao cấp), giỏ hàng và liên hệ.
